# PCOS intervention study — figure reproducibility scripts

R scripts for figures used in the manuscript comparing **PCOS, low-carbohydrate diet (LCD), Guizhi Fuling Capsule (GFC), and combination treatment (Combine)** in mice.

The project contains **seven scripts** corresponding to the manuscript's Figures 1–4 and Supplementary Figure S1. Results and generated images are written beneath the repository root; no institution-specific absolute paths are required. The supplied scripts preserve the analytical approaches in the authors' latest uploaded scripts rather than substituting new analyses.

## R environment

The scripts primarily use `ggplot2`, `dplyr`, `tidyr`, `readr`, `stringr`, `ggrepel`, `vegan`, `pheatmap`, `tibble`, `ggpubr`, `statmod`, `scales`, `ggVennDiagram`, and Bioconductor packages `limma`, `DESeq2`, `clusterProfiler`, `org.Mm.eg.db`, and the dependencies of these packages. Check and install these packages before running. The legacy omics scripts can also attempt to install missing packages when executed; for fully reproducible releases, record the R/Bioconductor versions and package snapshot after testing on the server.

Requirements include a modern R version supporting native `\(x)` lambda syntax (R >= 4.1). Some modules additionally require an internet connection for package installation or annotation resources. See the execution logs and `.work`/QC files for audit results.

## Run

From any working directory, locate the repository and run:

```bash
bash /path/to/PCOS_Multiomics_GitHub/check_inputs.sh
bash /path/to/PCOS_Multiomics_GitHub/run_all.sh
```

Or run one script directly:

```bash
Rscript scripts/01_bodyweight.R
Rscript scripts/02_HE_quantification.R
Rscript scripts/03_estrous_cycle.R           # requires real observed data
Rscript scripts/04_Fig2_single_treatments.R
Rscript scripts/05_Fig3_combination.R
Rscript scripts/06_Fig4_ovarian_RNA.R
Rscript scripts/07_Fig4G_cross_compartment.R
```

All paths are located relative to the R script, regardless of shell working directory. `run_all.sh` runs the reproducible Figure 1 panels first, skips the estrous script if observed data are missing, and stops before running the omics scripts if required omics inputs are absent.

## Figure output rules

Final individual figures are saved to `figures/` as PDFs and 400-dpi PNGs (Figure 1 uses 300 dpi, matching the uploaded scripts). Original omics scripts reduce widths/heights to 70% at export; individual font settings in each panel are not overwritten by a global theme. Figure 1 plots retain original panel export dimensions.

| Script | Final main-panel outputs | Supplementary outputs |
|---|---|---|
| `01_bodyweight.R` | Fig1E | — |
| `02_HE_quantification.R` | Fig1G, Fig1H | — |
| `03_estrous_cycle.R` | Fig1C, Fig1D (observed data only) | — |
| `04_Fig2_single_treatments.R` | Fig2A–D, Fig2E, Fig2F–H | FigS1C–F |
| `05_Fig3_combination.R` | Fig3A–D | FigS1A–B, FigS1G–I |
| `06_Fig4_ovarian_RNA.R` | Fig4A–F, Fig4H | — |
| `07_Fig4G_cross_compartment.R` | **Fig4G only** | — |

`Fig2E` and `FigS1I` are rendered directly through `pheatmap`, rather than the `save_plot` mapping. The final-panel filename mapping remains in each script for traceability to the historic figure code.

**Important Fig4G fix:** Script `06_Fig4_ovarian_RNA.R` may still calculate a six-metabolite display internally, but it **does not write `Fig4G`**. The sole owner of `figures/Fig4G.pdf`/`.png` is script `07_Fig4G_cross_compartment.R`, whose current panel shows group-adjusted residual correlations as a one-row, six-facet plot. This prevents the repeatedly encountered figure-overwrite issue.

## Scientific reproducibility and limitations

- The RNA-seq script uses DESeq2 with a 2×2 `~ LCD + GFC + LCD:GFC` factorial model; reported gene-level thresholds are BH-FDR < 0.05 and absolute log2 fold-change >= 1. The source count matrix can include noninteger expected counts: the legacy script rounds them, writing a QC audit. **Rounding may not reproduce vendor statistics exactly**.
- Figure 4 Venn regions are calculated from unique gene IDs, rather than deduplicated gene names. The code writes overlap-count audits to `.work/Fig4/QC/`.
- Genus-level CLR processing uses specified filters and a pseudocount; check `.work/Fig3/Tables/` and `.work/Fig4/` for the matched master CLR matrix.
- Figure 4G residualized Spearman correlations and their conventional `cor.test` P values are exploratory. They are not proof of metabolic transfer or causal circadian signaling; validate pairing and statistical inference before making confirmatory claims.
- Pooled genus–metabolite correlations may be driven by group differences. Metabolite annotations remain tentative unless verified with reference standards.
- Scientific panels are not equivalent to the full manuscript's assembled multipanel graphics. Figure 1A/B/F need source photos/time-line artwork not supplied as R scripts.
- **Before making a public release**, rerun every script on the actual data, check figure labels and sample pairing, review the exact input/output inventory, provide the processed matrices and QC artifacts promised in the manuscript, and consider depositing sequence data in a suitable controlled or public repository where required.

## Data availability and privacy

No personal identifiable information should be included in raw or processed data. The provided mouse IDs are analysis labels, not a verifiable cross-assay animal-key database. Confirm that each cross-omics mapping is valid before claiming complete animal-level pairing. Include original read-processing protocols separately if the submission requests them.
